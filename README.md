# Balvadoh Apparel

A luxury fashion e-commerce storefront built with React, Vite, and responsive design.

## Features

- Product catalog with filtering and search
- Product detail modals
- Shopping cart with quantity controls
- Responsive mobile design
- Editorial homepage
- Newsletter signup
- Quick add to bag

## Getting Started

```bash
npm install
npm run dev
```

Visit `http://localhost:5173`

## Build

```bash
npm run build
```

## Deploy to Vercel

1. Push this repository to GitHub
2. Visit [Vercel](https://vercel.com)
3. Click "New Project"
4. Connect your GitHub repository
5. Click "Deploy"

Your live site will be available at a Vercel URL.
